# Siyr Dance

Небольшой Fabric-мод для **Minecraft Java Edition 1.21.4**. Если корову назвать биркой ровно `Siyr` (регистр важен), она начинает косметический танец: вращается, подпрыгивает и выпускает из глаз красные частицы-лазеры. При запуске танца проигрывается зарегистрированный звук `siyr:siyr_dance`.

## Установка

1. Установите Java 21.
2. Установите Fabric Loader для Minecraft 1.21.4 и Fabric API 0.114.0+1.21.4.
3. Соберите мод командой `gradlew.bat build`.
4. Скопируйте `build/libs/siyr-1.0.0.jar` в папку `mods`.
5. В TLauncher выберите профиль Fabric **1.21.4**, запустите игру и положите туда же Fabric API и собранный JAR.

## Управление

В творческом режиме или с биркой переименуйте корову ровно в `Siyr`. Дополнительные команды и предметы не нужны. Чтобы остановить танец, переименуйте корову во что-либо другое.

## Собственный звук

Чужая аудиозапись в репозиторий не включена. Получите собственный лицензированный OGG-файл и назовите его `siyr_dance.ogg`, затем положите в ресурсный путь:

`src/main/resources/assets/siyr/sounds/siyr_dance.ogg`

Файл `sounds.json` уже зарегистрирован; после добавления OGG снова выполните `gradlew.bat build`. Музыкальная идея «Gdzie jest biały węgorz?» является только описанием желаемого звучания, а не включённой записью.

## Совместимость и ограничения

Сборка намеренно зафиксирована на Minecraft **1.21.4**, Java 21 и Fabric API 0.114.0+1.21.4. Для новых версий Minecraft потребуется отдельный порт и проверка Yarn/Fabric API API.

Состояние активации определяется по vanilla custom name коровы: это имя уже синхронизируется Minecraft между сервером и клиентами, поэтому отдельный mixin для `DataTracker` не нужен. Сервер запускает звук один раз при активации имени, клиентская часть через `ClientTickEvents` добавляет поворот, подпрыгивание и красные частицы. Лазеры чисто визуальные и не наносят урон. Такой подход не заменяет полноценную кастомную модель: отдельные копыта не анимируются независимо, а движение может слегка сглаживаться серверной интерполяцией.

Основная проверка проекта:
